# Quicky study on traffic levels during and post LTN intervention in Heaton, Newcastle upon Tyne

Repo to store code and data relating to the Heaton LTN which was put in place through October of 2022 and removed April 22nd 2024. 

- Analysis scripts can be found in the `code` folder
- data (including a polygon of the area and traffic sensor counts) can be found in the `data` folder
